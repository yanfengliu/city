# Lessons — evidence

The entry behind each rule in [lessons.md](lessons.md), in the same order. Not session-start reading: come here from a rule.

Empty is the healthy state — an entry leaves with its rule the moment a gate replaces it. `docs/learning/gate-proofs.md` records where each retired lesson's knowledge now lives and the mutation that proved the gate catches it.

Shape of an entry — the heading is what the rule links to, and the anchors are what make it a lesson rather than folklore:

```md
## The one-line claim, written to transfer

| Field | Value |
|---|---|
| Surfaced by | What was being done when it bit, and what was observed. |
| Reviewer findings | Who confirmed it and how, or n/a. |
| Fix commit | The SHA. |
| Test added | The test id, or n/a. |
| Behavior delta | What changed, the numbers that moved, and the rule that transfers. |
```
